# AGENT ROSTER

Repositorio base para una colección de agentes reutilizables. Cada archivo de `agents/` será la fuente de verdad de su identidad, rol, instrucciones, herramientas y permisos.

El panel visual se sirve desde `dist/` y permite explorar los arquetipos iniciales. Esta primera versión usa datos locales en el navegador: aún no ejecuta agentes ni guarda cambios en remoto.
