# AGENT ROSTER

Repositorio base para una colección de agentes reutilizables. Cada archivo de `agents/` será la fuente de verdad de su identidad, rol, instrucciones, herramientas y permisos.

El panel visual se sirve desde `dist/`. Permite activar unidades, crear misiones y mantener una cola en el navegador. La carpeta `runtime/` contiene el punto de partida para conectarlo después al [OpenAI Agents SDK](https://github.com/openai/openai-agents-python), sin exponer claves en el panel.
